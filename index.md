# EPR Gala Sales Automation

EPR Gala Sales Automation is an administrative tool used to manage deployment of the Gala Sales Demo application through Google Apps Script and GitHub Actions.

## Purpose

The application allows an authorized administrator to authenticate with Google and manage Google Apps Script projects and deployments.

This is an administrative utility, not a public sign-in service.

## Access

Access is restricted to authorized administrators. Google authorization is used for deployment and project-management operations.
